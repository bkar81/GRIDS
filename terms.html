What GRIDS is

GRIDS (Google-linked Report & Input Dashboard) is a client-side web application for configuring an input form, submitting entries to a Google Form, and displaying reports from a linked Google Sheet. GRIDS is provided as a Progressive Web App.

Your configuration and data

GRIDS stores its application configuration locally in your browser, including configured Form and Sheet links, fields, default values, and report layout. You are responsible for the accuracy of your configuration and for keeping backups of important information.

Google services

GRIDS can use Google Forms, Google Sheets, Google Drive, and Google authentication for features you configure or use. Those services remain subject to Google's own terms, policies, availability, and permissions.

Form submissions and reports

Home submissions are sent to the configured Google Form using its response mechanism. Report data is read from the configured Google Sheet after the required Google access is authorized. You are responsible for selecting the correct Form entry IDs, Sheet, fields, permissions, and report configuration.

Google Drive synchronization

Drive synchronization is optional. If enabled, GRIDS can synchronize its own configuration data with a GRIDS settings file in your Google Drive using Google's APIs. You are responsible for the Google account and Drive permissions used.

Backup and reset

GRIDS provides JSON export and import for configuration backup or transfer. Resetting GRIDS clears the locally stored GRIDS configuration on the current device; it does not delete the linked Google Form, Google Sheet, or Google Drive data.
