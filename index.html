What GRIDS does

GRIDS lets anyone submit an entry directly to a configured Google Form without logging in. The private Report and Settings screens use the data owner's Google account to read the linked Sheet and synchronize GRIDS's own configuration.

Features of GRIDS
Smart FormText, number, date and choice fields with dropdown/radio/checkbox display.
Master Data engineCentral sheet-driven values with per-row conditional logic using IN, CONTAINS, AND/OR and related operators.
Pivot ReportsMulti-field row grouping, column pivoting, sum/average/count/distinct-count aggregation.
Filters & SortingMulti-select filters and chronological sorting, including text-based dates.
Export & ShareCSV export plus image snapshot to clipboard/file/native share.
Drive SyncThree-way merge synchronization across devices with conflict resolution.
Backup/RestoreJSON export/import for moving GRIDS configuration between deployments.
Offline shellInstallable PWA with service-worker caching and update prompts.
Installing GRIDS

Open GRIDS in Chrome or another supported browser over HTTPS, then use the browser's Install app / Add to Home screen option. The PWA works as a standalone app and can use the cached shell when offline.

Data & privacy

Home sends the values you enter directly to the configured Google Form. GRIDS does not keep submitted entries in its own database. Report reads the linked Google Sheet only after you explicitly fetch/refresh it and Google access has been granted. GRIDS's local settings contain configuration, not Google login tokens.

Legal

GRIDS is a client-side utility. Google Forms, Google Sheets, Google Drive and Google authentication remain Google services subject to Google's own terms and policies. The GRIDS operator is responsible for the forms, sheets, data and permissions configured in the app.

Backups, help & policies

Keep a backup .json of each application (Settings → Sync → Export) and one all-applications backup (Welcome screen → Backup all apps). If something goes wrong: use Restore last working copy, import your .json, or restore from Google Drive.

Sharing / forking GRIDS

You can share the hosted GRIDS URL with other users. A fork/copy should use its own Google OAuth Web Client ID and its own configured Form/Sheet links. Exported JSON can transfer the GRIDS configuration, while each device signs into Google separately.
